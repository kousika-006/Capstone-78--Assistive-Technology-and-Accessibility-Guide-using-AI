Capstone 78 – AI-Driven Digital Accessibility and Inclusive Learning

📌 Project Overview

Capstone 78 focuses on using Artificial Intelligence and modern assistive technologies to create an inclusive digital learning experience. The project explores how AI-based solutions can help students with different accessibility needs understand and interact with educational content more effectively.

It examines technologies that support visually impaired, hearing-impaired, and other students who face difficulties accessing conventional digital learning materials.

The project explores AI tools such as ChatGPT, Google Gemini, ElevenLabs, Live Captions, and NotebookLM for generating image descriptions, improving captions, converting text into speech, and simplifying educational information.

A Python-based automation system is also developed to assist with accessibility-related prompt generation and content processing, supported by WCAG 2.1 Level AA guidelines.

🎯 Project Goals

- Make digital educational resources accessible to diverse learners.
- Explore AI-based methods for creating descriptive alternative text.
- Improve access to learning through speech and caption technologies.
- Compare and assess the capabilities of freely available AI tools.
- Encourage accessible document and content design.
- Ensure AI-generated results are reviewed for accuracy and reliability.

🛠️ Tools and Technologies

- Python – Automation and workflow development
- ChatGPT – AI-assisted content generation
- Google Gemini – Image understanding and descriptions
- ElevenLabs – Text-to-speech functionality
- Live Captions – Speech-to-text support
- NotebookLM – Research and document summarization
- NVDA and VoiceOver – Screen-reading technologies
- WCAG 2.1 AA – Accessibility reference standards

✨ Major Project Highlights

- Automated assistance for generating image Alt Text.
- Comparative evaluation of AI accessibility tools.
- Support for captions, speech conversion, and accessible learning materials.
- Python-powered accessibility prompt workflow.
- Practical accessibility recommendations for educators.
- Human validation process to identify incorrect AI-generated information.
- Inclusive learning checklist based on accessibility guidelines.

4. AI Tool Evaluation and Accuracy Analysis

6. Inclusive Learning Checklist

10. Interactive Demo Output

🌍 Expected Outcome and Social Impact

The project demonstrates how AI and assistive technologies can reduce digital learning barriers and improve educational participation.

By combining automated AI assistance with human verification and accessibility standards, this initiative promotes equal access to information and creates better learning opportunities for students with different abilities.
